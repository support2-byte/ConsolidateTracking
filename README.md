# RGSL Tracking (React + Vite)

    npm install
    npm run dev        # uses the "test" config in src/config.js
    npm run build      # uses the "live" config in src/config.js

All URLs and reCAPTCHA keys live in `src/config.js`.
Optional override: copy `.env.example` to `.env` and set `VITE_APP_ENV=test` or `live`.
